# University-Courses-Management-System

A Relational Database project developed using PostgreSQL and managed through pgAdmin 4. This project demonstrates database design, relational integrity, SQL constraints, CRUD operations, and queries across university-related tables.
______________________________________________________________________________________________________________________________________________________________________________________________________________________________________________

**📌 Project Overview**

The University Management System organizes academic information in a relational database. It demonstrates how students, departments, courses, instructors, and enrollments can be represented and connected using SQL.
______________________________________________________________________________________________________________________________________________________________________________________________________________________________________________

**🎯 Project Objectives**

- Design a structured relational database.
- Create tables with appropriate Primary and Foreign keys.
- Apply Constraints to maintain data integrity.
- Perform CRUD operations(Create, Read, Update, Delete) using SQL.
- Retrieve related information using JOIN queries.
- Practice database management with PostgreSQL and pgAdmin 4.
- Apply Aggregate Functions such as Count, Avg, Max.
______________________________________________________________________________________________________________________________________________________________________________________________________________________________________________
  
**🛠️ Technologies Used**

- PostgreSQL — relational database management system
- pgAdmin 4 — database administration and query tool
- SQL — database definition, data manipulation, and querying
- GitHub — project hosting and version control
______________________________________________________________________________________________________________________________________________________________________________________________________________________________________________

**🗂️ Database Tables**

Students| Stores student information
Departments| Stores department details
Courses| Stores course information
Instructors| Stores instructor information
Enrollments| Stores student enrollment records and related references
______________________________________________________________________________________________________________________________________________________________________________________________________________________________________________

**💡 Key Concepts Demonstrated**

- Database and Table Creation
- Primary keys and foreign keys
- NOT NULL and UNIQUE Constraints
- Referential integrity
- ON DELETE CASCADE or ON DELETE SET NULL, where configured
- INSERT, SELECT, UPDATE, and DELETE operations
- JOIN queries to retrieve related information
- WHERE, GROUP BY, HAVING, ORDER BY, LIMIT
- Subqueries
- Aggregate functions
- Date and string functions
- Window functions
- CASE expressions
